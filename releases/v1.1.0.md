# v1.1.0

First published GitHub Release of TM to Mumble Link, with native Linux and Windows
x86_64 downloads. The repository previously contained versions 1.0.0 and 1.0.1,
but had no published releases or version tags; this changelog covers all history
through this release, including that existing functionality.

## Native Linux support

- Run the bridge and Mumble natively on Linux while Trackmania's proximity-chat
  plugin sends data from Wine/Proton over localhost TCP.
- Use Mumble's POSIX shared-memory naming and native Linux wide-character layout,
  including Unicode player identities, via the existing `mumble-link` backend.
- Compile Windows APIs, tray integration, Alt-at-startup selection, and direct
  ManiaPlanet shared-memory telemetry only on Windows. Linux automatically uses
  the TCP plugin mode and a normal application window.
- Select Windows icon/resource compilation using Cargo's target OS.
- Add Linux setup and troubleshooting documentation, including the X11 runtime
  dependency found and fixed by the GUI integration test.

## Existing bridge functionality included in this first release

- Forward player and camera position/orientation from Trackmania to Mumble Link
  using framed TCP on `127.0.0.1:46323`, with JSON and binary position messages.
- Update player identity and server/team context; support ping, connection status,
  link application information, and shutdown messages.
- Provide a GUI for Mumble/game connection state, player/server details, positions,
  errors and update timing, with logging, icons, and UI polish.
- Clear server details on disconnect, improve channel-close handling and shutdown,
  and adjust window-visibility handling.
- On Windows, provide tray integration and an Alt-at-startup selector for direct
  ManiaPlanet telemetry, with position conversion, map context, player identity,
  and a scrollable telemetry display.
- Include the project's existing license in each binary archive.

## CI and releases

- Build and test Linux and Windows with the committed Cargo lockfile. Ordinary
  branch/PR CI now produces optimized binary archives as downloadable artifacts.
- Test complete/truncated binary packets and run the Linux GUI → TCP → Mumble
  shared-memory test against the optimized release binary, including JSON/binary
  positions, Unicode identity, and server context changes.
- Publish tagged releases only after both platform builds pass. Verify archive
  SHA-256 checksums and downloaded uploads while the release is still a draft,
  then publish and verify the release page and assets.
- Add a prepared-release PR route that creates a version tag and starts the same
  release workflow, plus `RELEASE.md` documenting changelog research, CI/review
  ownership, repairs, retries, and completion checks.

## Downloads and requirements

- **Linux x86_64:** extract the `.tar.gz`, then run `./tm-mumble-link`. Built on
  Ubuntu 24.04; use glibc 2.39+ and the desktop/graphics dependencies in README.
- **Windows x86_64:** extract the `.zip` and run `tm-mumble-link.exe`. The executable
  is unsigned.
- Each archive includes README, LICENSE and RELEASE.md, with a `.sha256` sidecar.
  Mumble and Trackmania are not bundled.

## Known limitations and manual checks

- Linux has no tray icon or direct ManiaPlanet shared-memory telemetry mode.
- Mumble and the bridge must run as the same user with access to the same shared
  memory. Restart the bridge after restarting Mumble.
- CI uses a Mumble-compatible memory fixture. Audible output with real players,
  Proton integration, Windows GUI behavior, and Wayland desktop behavior still
  require manual validation.
