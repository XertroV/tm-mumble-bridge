# v1.1.2

Patch release for Linux startup reliability and display-free operation.

- Fix the Wayland \`NoWaylandLib\` startup crash with supported Winit backend selection and XWayland fallback.
- Add the separate \`tm-mumble-link-tui\` client for headless, SSH, and no-XWayland environments.
- Add Linux backend regression coverage for X11, native Wayland, supplied sockets, missing libraries, and headless mode.
- Include both GUI and TUI executables in Linux and Windows release archives.

This release includes the fixes from [PR #7](https://github.com/XertroV/tm-mumble-bridge/pull/7).
